Optional: put librgd_hook.so here before "install" to get the turn-by-turn panel.

It is chefranov's route-guidance hook, v1.1.10, from
https://github.com/tehfalcon-vw/mhi2-nar-carplay-maps (its licence does not allow us to
include it). The installer accepts only that exact file:
SHA-256 @@RGD_HOOK@@

Without it you still get the CarPlay map in the cockpit, but no turn panel.
